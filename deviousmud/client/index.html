What is this?

DeviousMud is a tile-based multiplayer role-playing game that runs entirely in your browser. Ten skills, four quests, a village to call home, and nothing in it that a parent would rather you did not read.

Offline mode runs the identical game engine inside this tab, so you can play on a plane.
